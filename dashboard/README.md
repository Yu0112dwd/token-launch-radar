# Token Launch Radar — dashboard (token-radar-01)

Offline, static dashboard for the make.fun bounty **token-radar-01**
("Build the best token launch radar", $1,325 prize, deadline 2026-12-14 19:00 JST).

## How to open it (no network needed)

Option A — straight from disk (Chrome/Chromium needs one flag, because
`fetch("data.json")` from a `file://` page is blocked by default):

```
google-chrome --allow-file-access-from-files dashboard/index.html
```

Option B — any local static server, e.g. from the repo root:

```
python3 -m http.server 8000
# then open http://127.0.0.1:8000/dashboard/index.html
```

There are no external CDNs, fonts, scripts or network calls at runtime:
`index.html` + `styles.css` + `app.js` load only the local `data.json`.
The only `https://` strings are outbound link targets inside the data
(website / DefiLlama URLs) and the X/Twitter link built from a handle —
they are links you can click, not resources the page loads.

## Files

- `index.html` — page shell, header stats, filters, board table, detail view
- `app.js` — loads `data.json`, filtering/sorting, hash routing
- `styles.css` — dark theme, right-aligned numbers
- `data.json` — generated by `node main.ts` from `board.json` / `dossier.json`
  (do not hand-edit; re-run `node main.ts` from the repo root to regenerate)

## What it shows

- Header: 150 pre-token protocols, total TVL **$14,867,618,009**,
  total implied value **$3,864,020,163**, median implied value $5,915,909,
  27 categories. Source: DefiLlama, fetched 2026-11-24T12:30:40Z
  (9,100 protocols tracked, 353 eligible, top 150 shown).
- Method (also in `../data/METHODOLOGY.md`): implied value = TVL × category
  median mcap/TVL of tokenized comparables (global median fallback when a
  category has < 3 comparables), ratio capped at p75 × 1.5, 0.85 haircut for
  a 7d TVL fall worse than −20% or unaudited protocols, total capped at $5bn.
  This is a **proxy, not FDV** — DefiLlama reports market cap, not fully
  diluted valuation. **Not financial advice.**
- Board: sortable table of all 150 rows (rank, name, category, chains, TVL,
  7d change, implied value, confidence). Top 10 rows are highlighted.
  Click a column header or use the Sort control to re-sort.
- Filters: text search (name/slug), category, chain, minimum TVL slider,
  minimum confidence, sort order. The count line reads "X of 150 shown".
  "Clear filters" resets everything. Filters can also be deep-linked, e.g.
  `index.html?category=Lending`.
- Detail: click any row, or open `#/protocol/<slug>` directly, e.g.
  `#/protocol/polymarket-international`. Shows rank, category, chains,
  TVL + 7d change, implied value + full method string, category median
  ratio, confidence + reason, comparables table (name, mcap, TVL, ratio),
  numbered farm-plan steps, points/rewards note, risks, estimated
  cost/time, and links to website / DefiLlama / X where the data has them.
  A "Back to board" button returns to the board.
